Dozer Sandbox

Fast, suspendable Linux sandboxes for coding agents on your Mac. Each project gets its own small virtual machine that starts in about a third of a second, pauses in a millisecond, hibernates to disk and wakes with every program still running.

  • Run Claude Code, Codex or pi with permission prompts off. The VM is the boundary.
  • Every connection goes through a policy you can read. Your keys stay on your Mac.
  • Your project folder is /workspace inside. .dozignore keeps an agent out of secrets.
  • A dashboard in your browser for sandboxes, terminals, restore points and settings.

Install

An Apple silicon Mac with macOS 26 or later, and Homebrew:

brew trust --tap dozer-sandbox/tap
brew install dozer-sandbox/tap/doz-canary
doz ui

The dashboard opens on its setup wizard. Prefer the terminal? Run doz onboard, then doz up in a project folder.
